# v1.9 首个开源版本

HuntCrosshair 是面向 Windows 10 / 11 x64 的轻量外置准星工具。本次以 v1.9 作为首个公开版本，项目采用 MIT 许可证。

- 可调准星颜色、长度、间隔、厚度、透明度、角度与像素尺寸。
- 支持几何居中、亚像素微调和自绘像素准星。
- 支持右键渐隐、收拢为中心点及三次贝塞尔动画。
- 提供默认和复古皮肤，支持七项自定义全局快捷键。
- 预览带立体边框，右下角“右键”按钮用于切换模拟状态。
- 设置实时应用并自动保存到程序旁的 INI 文件。

下载 HuntCrosshair-Portable-v1.9.zip 后解压运行 HuntCrosshair.exe。升级时先退出正在运行的程序，再保留同目录 INI 配置并替换 EXE。

源码构建使用 Zig 0.13.0。核心、配置、画板与模态窗口测试通过，原生界面检查共 551 项通过。游戏覆盖支持窗口和无边框全屏，实际游戏兼容性仍需实机验证。

发布附件包括便携包、单文件 EXE、完整源码包、许可文件包和 SHA256 校验文件。便携包已附许可文件，单文件 EXE 可搭配 HuntCrosshair-Licenses-v1.9.zip 下载。运行时组件的许可见 THIRD_PARTY_NOTICES.md 和 licenses 目录。
